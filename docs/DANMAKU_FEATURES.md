# 无音影视 v1.8.6 弹幕功能增强包

## 本包实现
- 新增 DanmakuService：解析 Bilibili XML、ASS、SRT 与逐行文本弹幕。
- 播放器按视频当前播放时间渲染弹幕，暂停/定位时跟随播放器时间；使用时间轴位置实现右向左滚动，并按 lane 分轨及按密度过滤。
- 本地弹幕文件通过系统 DocumentViewPicker 导入，文件大小限制 8 MiB。
- 在线弹幕：使用 Bilibili 视频搜索 API 展示候选，用户确认匹配的视频/分集后加载对应 CID XML 弹幕。此实现不是跨所有视频站点的通用弹幕服务。
- 字号、透明度、速度、密度/同步开关保存在 preferences。
- 协播命令增加可选 danmaku 字段，主控发布有限大小的弹幕包，接收端校验后更新；旧客户端可忽略该字段。

## 重要限制
- 未在本执行环境运行 DevEco Studio/Hvigor 编译，未进行鸿蒙真机、跨版本、双设备或在线 API 实测。
- Bilibili 接口可能因风控、网络策略、接口变化、地区/账号限制而失败；搜索结果需要用户确认正确影片/分集，不保证所有影视都能自动匹配。
- ASS 只解析 Dialogue 基本文本与起始时间，忽略复杂样式、定位与特效；SRT 转换为按起始时间显示的滚动弹幕，不保留字幕时长语义。
- 协播弹幕通过现有主控状态发布节奏传输，包大小受到限制；大弹幕库不会完整广播，建议主控/接收端先加载同一弹幕源。需要真机验证网络/AVSession 中继路径。
